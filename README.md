# FIFA World Cup 2026 AI Assistant & Operational Intelligence

This project is a dynamic, AI-powered web application built for the FIFA World Cup 2026. It features two main views:
1. **Fan Experience**: An interactive chatbot for fans to ask questions about stadium navigation, sustainability, match info, and transportation. Powered by Google's Gemini API.
2. **Staff Dashboard**: A real-time venue operations dashboard that analyzes sensor data and generates operational insights to assist staff in managing crowd flows and ensuring a safe environment.

## Features
- **AI Chatbot**: Multilingual support for fans using Gemini 2.5 Flash.
- **Operational Intelligence**: Real-time insights generated from mock stadium sensor data (e.g., Gate Density, Transport Hub Flow).
- **Modern UI/UX**: Built with HTML, CSS (glassmorphism design), and Vanilla JavaScript.

## Setup Instructions

1. Clone this repository:
   ```bash
   git clone https://github.com/Mr-K3yur/Challenge4.git
   ```
2. Open `index.html` in your web browser.
3. Click on the **"Set API Key"** button or use the modal on startup to enter your Google Gemini API Key.
4. Start exploring the Fan Experience and Staff Dashboard!

- HTML5
